# Meet 02 - Dasar Go

Materi sesi ini fokus pada syntax dasar Go dan ditutup dengan mini project CLI.

## Struktur

```text
meet-02/
├── materi/
│   ├── 01-hello-print/
│   ├── 02-variable-constant/
│   ├── 03-input-scan/
│   ├── 04-operator/
│   ├── 05-conditional/
│   ├── 06-loop/
│   ├── 07-function/
│   ├── 08-slice-map/
│   ├── 09-struct/
│   └── 10-error-handling/
└── mini-project/
    └── cli-kasir/
```

## Cara Run

```bash
go run ./materi/01-hello-print
go run ./materi/09-struct
go run ./materi/10-error-handling
go run ./mini-project/cli-kasir
```

## Alur Belajar

1. Print output dengan `fmt.Print`, `fmt.Println`, dan `fmt.Printf`.
2. Variable, constant, tipe data dasar, dan short declaration.
3. Input sederhana dengan `fmt.Scanln`.
4. Operator aritmatika dan perbandingan.
5. Percabangan `if`, `else if`, `else`, dan `switch`.
6. Perulangan `for`.
7. Function dengan parameter dan return value.
8. Slice dan map untuk kumpulan data sederhana.
9. Struct untuk membuat tipe data sendiri.
10. Error handling dengan `error`, `nil`, dan early return.
11. Mini project CLI kasir sederhana.
